# Weather Live 24/7

A responsive weather dashboard built with HTML, Tailwind CSS, JavaScript, Font Awesome, and the OpenWeather API.

## Live Demo

https://jojin1709.github.io/weather-live-24-7/

## Features

- Search weather by city
- Use current location weather
- Current temperature and weather condition
- Hourly forecast
- 5-day forecast
- Weather details like humidity, pressure, visibility, wind, sunrise, and sunset
- Air quality information with AQI guide
- Recent searches
- Favorite cities
- Dark/light theme toggle
- Weather-based background
- Responsive design for mobile, tablet, and desktop

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Font Awesome
- OpenWeather API
- GitHub Pages

## Air Quality Guide

- AQI 1 = Good
- AQI 2 = Fair
- AQI 3 = Moderate
- AQI 4 = Poor
- AQI 5 = Very Poor

## Note

This project is hosted on GitHub Pages, so the OpenWeather API key is used directly in the frontend JavaScript.
